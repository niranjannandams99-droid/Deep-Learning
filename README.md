## ⭐ Featured Project

### SoundSafe Kitchen

A deep learning-based audio classification application designed to identify potential kitchen hazards using passive audio signals.

The project uses a **1D Convolutional Neural Network (CNN) with Temporal Self-Attention** to learn meaningful patterns from audio data and generate hazard predictions.

### Highlights

- 🎙️ Audio-based hazard detection
- 🧠 1D CNN architecture
- 🎯 Temporal Self-Attention mechanism
- 🎵 Mel-Spectrogram based feature representation
- 📊 Model performance evaluation
- ⚡ Fast model inference
- 🚀 Streamlit-based deployment
- 💻 Real-world AI application

### Technologies Used

- Python
- PyTorch
- CNN
- Temporal Self-Attention
- Audio Signal Processing
- Mel-Spectrogram
- NumPy
- Streamlit
